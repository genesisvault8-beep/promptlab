# PromptLab

**AI prompt engineering workspace by [GenesisVault](https://genesisvault.xyz)**

🔗 **Live:** https://promptlab.genesisvault.xyz

Engineer, test, compare and save AI prompts using Claude, ChatGPT and Gemini through OpenRouter. No accounts. No servers.

## Features

### 🤖 Prompt Agent
Describe your goal and the agent generates 3 prompt variations, tests them all against AI, judges the winner and refines it automatically. No manual iteration.

### 🎨 Style Extractor
Paste any novel, story or article. The agent extracts the writing style, tone and patterns, then turns them into reusable prompt templates.

### ✍️ Prompt Editor
Write system and user prompts, pick your model, and tune max tokens and temperature. Run against Claude, ChatGPT or Gemini and see the output instantly.

### ⚖️ Compare Mode
Run two prompt variations side by side. AI judges which output is better, with real scoring instead of random numbers.

### 📚 Prompt Library
15 ready-made templates across writing, code, marketing, security and analysis. One click to load and customize.

### 💾 Save & Restore
Save your best prompts locally, load them back anytime and export to JSON. No account needed.

### 📊 Prompt Analyzer
Instant feedback on clarity score, token count and word count, so you know your prompt is well structured before you run it.

### 🔑 BYOK (Bring Your Own Key)
Paste your [OpenRouter API key](https://openrouter.ai/keys) once. It stays in your browser, and you pay OpenRouter's standard rates with no markup.

### 📱 Installable PWA
Add PromptLab to your phone or desktop home screen like a native app.
